# Password and Authentication Policy

- Passwords must be at least **16 characters** long. Length matters more than symbols; passphrases are encouraged.
- Multi-factor authentication is mandatory on SSO, email, the code hosting platform and the cloud consoles.
- Passwords on shared service accounts rotate every 90 days and live in the approved password manager.
- Never reuse a work password on a personal site. If a breach notification names your work email, change the password the same day.
