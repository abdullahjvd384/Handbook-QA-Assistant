# Access Request Process

Request access to systems through the IT portal. Each request is routed to the system owner for approval; your manager is copied. Standard requests are fulfilled within **48 hours** of approval. Production database access additionally needs sign-off from the Security Lead and is reviewed every quarter.

Access is removed automatically on the last working day. Contractors' access expires with their contract end date and must be renewed by the sponsoring manager.
